# 야모네 (Yamone)

야모네는 일상 기록과 생활 기능을 하나의 앱으로 묶는 개인용 Android 앱 프로젝트입니다.

## 현재 구성

- 알람
- 수면 기록 / 코골이 후보 분석
- 활동 (걷기·러닝 / 자전거)
- 스키·스노보드 (추후 구현)
- 민트 / 핑크 테마
- 아기물범 / 아기곰 캐릭터 테마

## UI 기본 구조

모든 주요 화면과 서브 화면은 다음 구조를 기본으로 합니다.

- 상단 고정 헤더
- 가운데 콘텐츠만 스크롤
- 하단 5탭 고정: 알람 | 수면 | 홈 | 활동 | 스키
- Android 상태바 아래 안전 여백 확보

## 관련 프로젝트

- `Yamone-Games`: 스도쿠, 네모로직 등 미니게임 프로젝트
- 향후 Yamone 본체에 게임 메뉴로 통합 예정

## 개발 원칙

- 개인정보와 수면/활동 기록은 기본적으로 휴대폰 로컬 저장
- 외부 유료 API 및 별도 서버 의존 최소화
- 기능 구현 전 라이선스·약관·개인정보·플랫폼 정책 검토
- 승인된 디자인은 기능 구현 시 임의 변경하지 않음
