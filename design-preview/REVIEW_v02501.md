# v0.25.01 — 방문 순서대로 뒤로가기

범위: 시스템 뒤로가기와 종료 확인만. v0.24.03의 CSS/PNG 및 나머지 목업을 유지한다. 요약보기 화면 및 실제 GPS 기능은 이번 버전에 추가하지 않는다.

- 홈 → 기록 → 알람 → 홈 → 활동 → 설정 방문 후 Back: 활동 → 홈 → 알람 → 기록 → 홈.
- 중간에 방문한 홈에서도 이전 방문 기록이 남아 있으면 종료하지 않는다.
- 더 돌아갈 화면이 없을 때만 취소 / 나가기 확인을 표시한다.
- 취소 또는 열린 팝업에서 Back: 팝업만 닫고 현재 화면을 유지한다.
- 나가기: Activity/자체 태스크를 마무리하고 Android가 이전 앱/화면을 표시하도록 한다. HOME/다른 앱 실행 Intent는 사용하지 않는다.
- Android 13+는 OnBackInvokedCallback, 이전 버전은 onBackPressed를 같은 JS history에 연결한다.
- 화면 새로 그리기, 설정 스위치 변경, 일시정지 등의 상태 변경은 방문 기록을 중복 생성하지 않는다.
- 상단 뒤로가기도 같은 기록을 소비하므로 상세/목록을 반복 왕복하지 않는다.
- 방문 기록은 현재 앱 실행 중 메모리에 유지한다. 앱을 새로 시작하면 홈에서 새 기록을 시작한다.

검증: 격리된 Chromium에서 32개 확인 항목 통과(탭 방문 역순, 중간 홈, 취소/나가기 브리지, 반복 탭, Back 이후 새 방문, 상세/설정/알람 복귀, 팝업 우선 닫기, 320/360/390/430px 팝업 버튼). JS 런타임 오류 없음. 네이티브 빌드/실기기 Back 버튼 및 제스처는 별도 확인 대상이며 브라우저 테스트를 실기기 검증으로 간주하지 않는다.
