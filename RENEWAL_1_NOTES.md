# Yamone Renewal 1

Implementation preview applied to the Android app shell.

- Stronger 2dp card borders
- Hand-drawn Canvas icons (no emoji/system icon dependency)
- Five bottom tabs with custom icons
- One combined `걷기 · 달리기 · 자전거` activity card
- Snow represents both ski and snowboard
- Seal-first activity artwork
- Thick right chevrons on all activity cards
- Record month chevrons aligned to the far right and vertical (down/up)
- Larger activity artwork and reduced left/text spacing
- Mint / Pink theme support retained
- Existing alarm function remains reachable

Version: `0.4.1-renewal-1`
